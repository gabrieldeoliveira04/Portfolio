# First Personal Portfolio Website

Primeiro portfólio pessoal desenvolvido com HTML, CSS e JavaScript puro, criado com o objetivo de apresentar minhas habilidades iniciais em desenvolvimento web frontend e fortalecer minha presença profissional online.

O projeto foi desenvolvido durante meu processo de aprendizado em desenvolvimento web, servindo como uma das primeiras aplicações completas criadas por mim, incluindo estruturação visual, estilização, responsividade e publicação online.

Além da construção da interface, o projeto também foi utilizado para praticar deploy de aplicações frontend e organização de projetos web.

## Objetivo do Projeto

O principal objetivo do projeto foi desenvolver meu primeiro portfólio profissional para apresentação de habilidades, tecnologias estudadas e projetos pessoais.

Além disso, o projeto também teve como foco praticar fundamentos essenciais do desenvolvimento web utilizando HTML, CSS e JavaScript puro.
